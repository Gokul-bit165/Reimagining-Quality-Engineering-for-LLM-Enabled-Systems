Know if your AI app is safe to ship. With evidence.

Paste the GitHub link of your RAG app. We test it, score it with honest confidence intervals, and recommend Release, Conditional or Reject for a human to sign.

The problem

A few good prompts are not release confidence.

The workflow

From a GitHub link to a signed release decision.

How it stays honest

AI proposes. Deterministic code decides.

No language model writes to the ledger, computes a metric or issues a verdict. Text from models and from your repo is treated as untrusted input.

System architecture

What runs where, and what it never touches.

Everything runs on your machine. External calls are limited to GitHub (shallow, read-only clone) and, only if you enable it, an LLM provider for question generation. Your repository's code is analysed as text and never executed on the host.

Tests are generated, not a fixed list

Every risk spawns varied tests. Every failure seeds the next round.

Security judged by what actually happened

A planted secret either reaches the output, or it does not.

The verdict comes from an outcome oracle watching the sink, never from an AI saying "blocked". Attack results are reported as success rate at a stated attempt budget, with an interval.
