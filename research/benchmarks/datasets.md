# Datasets — Access, Licensing and Use Notes

**Status: licensing and access methods NOT verified.** This file lists what must be checked per dataset before use; nothing here is legal advice.

## Checklist per dataset
Source paper · version · size/splits · label provenance (human/LLM/programmatic) · annotation protocol & agreement · license text (commercial use? derivative use? attribution? share-alike?) · terms of any underlying model outputs (e.g., generated by commercial LLMs — provider terms may restrict training/evaluation use) · hosting (HF/GitHub/other) · contamination exposure (appears in training data of target or judge models?) · known errors.

## Dataset-specific cautions identified
| Dataset | Caution |
|---|---|
| RAGTruth | Responses produced by commercial and open LLMs; check provider-term constraints and dataset license. Vectara reports HHEM-2.1-open trained with RAGTruth data among others → any HHEM-based verifier evaluated on RAGTruth is **contaminated** (✔S). |
| LLM-AggreFact | Aggregated from multiple sources with different licenses → license is likely per-source; check. |
| S-Eval | Auto-generated safety prompts; potentially harmful content; handle under sandbox rules. |
| AgentDojo / InjecAgent | Contain attack strings; use only in sandbox; ensure usage aligns with repo license. |
| τ-bench | Uses LLM-simulated users; results depend on user-model choice (noted in course slides ◐2). |
| RewardBench-family | Preference labels partly subjective (κ=0.29 human–LLM in one study ✔P). |
| Any dataset used to calibrate a verifier | Hold out a calibration set disjoint from the evaluation set; record IDs. |
